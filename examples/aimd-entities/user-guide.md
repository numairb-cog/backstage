# User Guide

Welcome to the platform user guide! This documentation will help you get started with using our platform effectively.

## Getting Started

To begin using the platform, follow these steps:

1. **Sign in** to your account
2. **Navigate** to the dashboard
3. **Explore** the available features

## Key Features

### Feature 1: Service Catalog

The service catalog allows you to browse and discover all services in your organization.

- View service details
- Check service health
- Access service documentation

### Feature 2: Software Templates

Create new projects quickly using our pre-built templates:

```bash
# Example command
backstage-cli create-app
```

### Feature 3: TechDocs

Access technical documentation directly within the platform.

## Best Practices

> **Tip**: Always keep your service metadata up to date for better discoverability.

### Naming Conventions

Use clear, descriptive names for your services:

- Use lowercase with hyphens
- Include the team or domain prefix
- Example: `payments-api`, `user-service`

## Troubleshooting

### Common Issues

| Issue                  | Solution                  |
| ---------------------- | ------------------------- |
| Cannot access service  | Check your permissions    |
| Service not found      | Verify the service name   |
| Documentation outdated | Contact the service owner |
